# Water Quality Monitoring Dashboard

## About the Project

The Water Quality Monitoring Dashboard is an academic project developed to demonstrate how digital technology can help monitor water quality and identify potential pollution.

It provides a dashboard to visualize important water quality parameters such as pH, Dissolved Oxygen, Turbidity, TDS, and Temperature.

The project also includes CSV data upload and export, ThingSpeak integration, pollution alerts, trend analysis, and rule-based insights.

## Features

- Water Quality Dashboard
- pH Level Monitoring
- Dissolved Oxygen Monitoring
- Turbidity Monitoring
- TDS Monitoring
- Temperature Monitoring
- CSV Data Upload and Export
- ThingSpeak Integration
- Pollution Alerts
- Trend Analysis
- Rule-Based Insights
